# Weather Dashboard

A weather app built with plain HTML, CSS and JavaScript. Search a city to see its current weather and a 5-day forecast. No framework and no API key needed.

**Live demo:** YOUR-VERCEL-LINK

## Features
- Search by button or Enter key, with autocomplete suggestions
- Current weather and a 5-day forecast
- Loading message and friendly error messages (empty input, city not found, no internet)
- Light / dark mode and °C / °F toggle, both remembered with localStorage
- Recent searches saved as clickable chips
- Card colour changes with the weather
- Responsive layout (side by side on laptop, stacked on phone)
- Rotating scenery photo banner

## APIs used
[Open-Meteo](https://open-meteo.com/) geocoding and forecast APIs (no key needed).

## How to run
Open `index.html` in a browser. An internet connection is needed for live data.
